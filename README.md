# Agenda Personalizada Nails (MinhaAgenda)

Aplicativo mobile de agenda personalizada para profissionais de nails (manicure e nail designer): agendamento de clientes, controle de horários e serviços.

## Design

O design do projeto está no Figma:

- **Arquivo Figma:** [MinhaAgenda — Fluxo de Páginas e Identidade Visual](https://www.figma.com/design/iTZZOI3KZwIkgRNLdkFLlh/MinhaAgenda-%E2%80%94-Fluxo-de-P%C3%A1ginas---Identidade-Visual--c%C3%B3pia-)

Páginas do arquivo:

1. **01 · Identidade Visual** — cores, tipografia e elementos da marca
2. **02 · Fluxo de Páginas** — mapa de navegação entre as telas
3. **03 · Telas (Cliente & Admin)** — telas do app para cliente e para administração
